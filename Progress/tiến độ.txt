TIEN DO DU AN POS DESKTOP
Cap nhat gan nhat: 2026-06-14

1. Trang thai hien tai
- Du an la ung dung POS desktop bang Python + PyQt6.
- Supabase la backend chinh cho auth, users, registers, products, product images, sales, inventory, realtime va edge functions.
- SQLite van duoc dung lam local cache/offline store tai `%LOCALAPPDATA%\RetailPOS\pos.db`.
- App chay tu `main.py`, thu khoi phuc session da luu, sau do mo `PosMainWindow`.
- `app_paths.py` quan ly duong dan `.env`, runtime DB va cache.
- UI chinh dung QStackedWidget va sidebar theo role/permissions.
- Nhom tinh nang hien co:
  + Login/register store owner, giu phien dang nhap, logout.
  + POS Terminal, checkout, split payment, receipt preview.
  + Product Management: add/edit modal, barcode, image upload/cache, label printing, sync status, retry.
  + Admin: users, registers, reports, audit logs, settings.
  + Background sync, realtime dirty-event sync, network/offline notification.
  + Light/dark theme toggle runtime.

2. Cac thay doi hien tai / da hoan thanh
- Chuyen project tu local-only sang Supabase-first.
- Them `cloud/`:
  + `cloud/supabase_client.py`: doc `.env` va tao Supabase client.
  + `cloud/auth.py`: login, register store owner, profile, restore session, admin edge functions.
  + `cloud/products.py`: product CRUD, barcode sync, Storage upload/download, inventory adjustment.
  + `cloud/inventory.py`: `checkout_sale`, recent sales, sale items/payments, registers.
- Them cac truong local de sync: `store_id`, `cloud_id`, `sync_status`, `sync_error`, `last_synced_at`, `deleted_at`.
- Cache Supabase profile vao local users table.
- Luu Supabase session token trong luong remember login.
- Them UI register store owner.
- Product Management dung cloud-required save/delete voi cloud store.
- Bang product hien sync state va co retry khi pending/error.
- Anh product upload len Supabase Storage va cache ve local.
- Checkout uu tien Supabase RPC `checkout_sale` de sale/payment/stock commit cung nhau.
- Offline checkout chi mo cho Admin, luu local `pending_offline` de sync sau.
- Them retry pending product/sale.
- Them background sync timer va realtime worker.
- Them network status/friendly error notification.
- Them light/dark theme va nut toggle runtime.
- Cap nhat flow build PyInstaller + Inno Setup.

3. File chinh
- `main.py`
  Entry point; tao QApplication, init auth DB, restore user, mo main window.
- `app_paths.py`
  Resolve project/external root, `.env`, user data dir, DB path, cache dir.
- `pos_terminal.py`
  Wrapper giu lenh chay cu.
- `login/login_window.py`
  Supabase login/register, local auth cache, session, users/registers/shifts/settings/audit helpers.
- `database/db.py`
  SQLite schema, query product/sale, validate inventory, local cache, cloud sync, offline pending sale retry.
- `cloud/*`
  Supabase client/auth/product/inventory integration.
- `pos_terminal/pos_window.py`
  Main shell, sidebar, POS, cart, checkout, receipt, background sync, realtime sync, theme toggle, logout.
- `pos_terminal/realtime_worker.py`
  Supabase realtime listener de queue local sync.
- `product_management/product_management_window.py`
  Product list, ProductDialog, barcode validation, image selection, label printing, sync status/retry.
- `product_management/label_printing.py`
  Print/preview label.
- `admin/*`
  Dashboard, users, registers, reports, audit logs, settings.
- `ui/theme.py`
  Light/dark styles va combo popup fix.
- `ui/loading.py`
  Blocking/background task runners va timeout overlay.
- `ui/notifications.py`
  Friendly errors, toast notifications, network status.
- `build_exe.ps1`
  Script build PyInstaller.
- `build_installer.ps1`
  Script staging/build installer bang Inno.
- `installer/RetailPOS.iss`
  File Inno Setup.

4. Runtime data
- Supabase la data chinh cho production/cloud store.
- SQLite la local cache/offline support, khong duoc package.
- DB mac dinh:
  + `%LOCALAPPDATA%\RetailPOS\pos.db`
- Override khi dev:
  + `POS_DB_PATH=...`
- Product images:
  + source: Supabase Storage bucket `product-images`
  + cache: `%LOCALAPPDATA%\RetailPOS\cache`
- `.env` duoc tim o:
  + folder canh installed exe
  + project root khi development

5. Database va sync
- Bang local quan trong:
  + stores
  + roles
  + users
  + registers
  + cash_shifts
  + cash_movements
  + audit_logs
  + settings
  + products
  + product_barcodes
  + sales
  + sale_items
  + sale_payments
  + sync_queue
- Product sync:
  + cloud store dung `save_product_cloud_required()`.
  + pending/error co the retry.
  + pull tu cloud update cache local va inactive product khong con tren cloud.
- Sale sync:
  + checkout binh thuong goi RPC `checkout_sale`.
  + local sale duoc luu `synced` sau cloud success.
  + Admin offline sale duoc luu `pending_offline`.
  + retry se push pending sale len cloud.
- Background sync:
  + retry pending products/sales
  + pull products
  + pull recent sales
  + refresh users/registers
- Realtime sync:
  + event cloud danh dau dirty product/sale
  + main window queue sync theo loai du lieu

10. Build va Installer
- Setup:
  + `.\setup.ps1`
- Run source:
  + `.\.venv\Scripts\python.exe main.py`
- Build EXE folder:
  + `.\build_exe.ps1`
- Build one-file EXE:
  + `.\build_exe.ps1 -OneFile`
- Build installer:
  + `.\build_installer.ps1`
- Installer output:
  + `installer\Output\RetailPOSSetup.exe`
- Cai vao:
  + `%LOCALAPPDATA%\Programs\RetailPOS`
- Build chi bundle asset UI bat buoc, khong bundle `assets\products`.
- Installer include `.env` hien tai; chi dung `SUPABASE_ANON_KEY`, khong dung service-role key.
