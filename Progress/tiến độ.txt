TIEN DO DU AN POS DESKTOP
Cap nhat gan nhat: 2026-05-13

1. Trang thai hien tai
- Du an la ung dung POS desktop viet bang Python + PyQt6.
- App chay theo mo hinh mot cua so chinh PosMainWindow, noi dung doi bang QStackedWidget.
- Sidebar ben trai dieu huong giua POS Terminal, Product Management, dashboard va cac trang admin theo quyen.
- Database dung SQLite built-in cua Python thong qua sqlite3.
- File database runtime chinh la pos.db nam o thu muc goc project.
- POS Terminal doc products de ban hang va luu giao dich vao sales, sale_items, sale_payments.
- Product Management quan ly products.
- Admin pages hien co: dashboard, user management, register management, reports, audit logs, settings.
- Global synchronization da duoc them bang pyqtSignal de cac trang reload data sau khi DB thay doi.

2. Danh sach da sua gan day
- Them app_data_changed = pyqtSignal() trong PosMainWindow.
- Them notify_app_data_changed() de phat signal refresh toan app.
- Them connect_global_refresh() de noi app_data_changed voi cac trang co ham reload/load data.
- Them get_reload_handler() de tu dong tim ham reload phu hop cua tung page.
- Them reload_data() trong PosMainWindow de reload product grid va refresh total.
- Them shortcut Shift+F5 de ep reload data toan app.
- Them data_changed = pyqtSignal() vao ProductManagementWindow.
- Them reload_data() vao ProductManagementWindow.
- Sau Add/Update/Delete Product se phat data_changed.
- Them data_changed va reload_data vao UserManagementWindow.
- Sau Add/Update/Delete User se phat data_changed.
- Them data_changed va reload_data vao RegisterManagementWindow.
- Sau Add/Update/Delete Register se phat data_changed.
- Them data_changed va reload_data vao SettingsWindow.
- Sau Save Store Settings va Save Other Settings se phat data_changed.
- Sau Pay Cash va Split Payment thanh cong, POS phat global refresh de dashboard/report cap nhat.
- Product card trong POS hien Barcode thay vi ID.
- Nút xoa item trong cart la chu X mau do dang icon nhe.
- Cart table da bat vertical scrollbar luon hien thi.
- Cart table da tat horizontal scrollbar de tranh lech layout.
- Cart table dung ScrollPerItem va scrollToBottom() sau khi populate.
- Cart table duoc gioi han chieu cao min/max de khong che khu totals/action buttons.
- Da them style scrollbar doc de nguoi dung thay ro co the keo xuong.

4. Global synchronization hien tai
- PosMainWindow co signal chung:
  app_data_changed = pyqtSignal()

- Cac page ghi DB co signal rieng:
  + ProductManagementWindow.data_changed
  + UserManagementWindow.data_changed
  + RegisterManagementWindow.data_changed
  + SettingsWindow.data_changed

- Khi page con phat data_changed:
  page.data_changed -> PosMainWindow.notify_app_data_changed() -> app_data_changed.emit()

- PosMainWindow.connect_global_refresh() se noi app_data_changed den ham reload phu hop cua moi page.

- Thu tu tim reload handler:
  + reload_data
  + load_dashboard_data
  + load_products
  + load_users
  + load_registers
  + load_settings
  + load_report
  + load_logs

- Shift+F5:
  + Khi nhan Shift+F5, app goi notify_app_data_changed().
  + Tat ca page da connect se reload data ma khong can restart app.

5. Database hien tai
- database/db.py tao/migrate cac bang can thiet trong init_db().
- Cac bang chinh dang co:
  + products
  + sales
  + sale_items
  + sale_payments
  + sync_queue
- products co cac cot mo rong nhu sku, stock_qty, active, updated_at.
- sales co user_id, register_id, shift_id, total_amount, payment_method, tendered_amount, change_amount, status, created_at.
- sale_items co product_id, barcode, name, qty, price, subtotal.
- sale_payments luu cac payment method cua 1 sale.
- sync_queue phuc vu viec dong bo/offline sau nay.

6. POS Terminal hien tai
- Layout POS co 3 khu:
  + Sidebar ben trai.
  + Product grid o giua.
  + Cart + totals + action buttons ben phai.
- Product grid:
  + Search/scan bar o tren.
  + Product cards hien placeholder image, product name, barcode, price.
  + Click product card de add vao cart.
  + Nhan Enter trong search de tim theo barcode/name.
- Cart:
  + Columns: Name, Qty, Price, Total, X.
  + Qty cho double-click de sua.
  + Qty <= 0 thi xoa item.
  + Nut X mau do de xoa item.
  + Vertical scrollbar luon hien thi, co the keo xuong khi nhieu item.
  + Khi add item moi, table scroll xuong duoi.
- Totals:
  + Subtotal
  + Discount
  + Grand Total
- Actions:
  + Pay
  + Split Payment
  + Cancel

7. Payment hien tai
- Pay:
  + Mo Payment QDialog.
  + Ben trai hien Total Due, Amount Tendered, Change, Note.
  + Ben phai co radio Cash va Bank Transfer.
  + Nut Print preview receipt.
  + Nut CONFIRM luu sale vao DB, hien Payment Successful, hien Receipt Preview, clear cart.
- Split Payment:
  + Mo Split Payment QDialog.
  + Co Cash va Card/Transfer input.
  + Neu tong tien >= Grand Total thi luu sale method Split.
  + Hien Receipt Preview va clear cart.
- Cancel:
  + Hoi xac nhan void transaction.
  + Neu Yes thi clear cart, reset discount/total.
- Sau Pay/Split thanh cong:
  + Goi notify_app_data_changed() de dashboard/reports reload.

8. Receipt Preview hien tai
- Sau Pay hoac Split thanh cong, app tao receipt text va hien trong QDialog.
- Receipt co:
  + MY POS SHOP
  + Date/time
  + Payment method
  + Items: name, Qty, Price, Amount
  + Total
  + Tendered
  + Change
  + Thank-you line
- Receipt hien bang QTextEdit read-only font Consolas.
- Chua luu receipt.txt ra file.

9. Product Management hien tai
- File chinh: product_management/product_management_window.py.
- La QWidget page nam trong QStackedWidget.
- Form dung QFormLayout.
- Search realtime bang textChanged.
- Table columns:
  + No.
  + Barcode
  + Product Name
  + Price
  + Category
  + Requires Weight
- No. la so thu tu hien thi, ID that luu trong UserRole.
- Add/Update/Delete product se reload table va emit data_changed.

10. Cach chay app
- Cai moi truong:
  .\setup.ps1

- Chay app chinh:
  .\.venv\Scripts\python.exe main.py

- Lenh cu van chay duoc:
  .\.venv\Scripts\python.exe pos_terminal.py
