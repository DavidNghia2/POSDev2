TIEN DO DU AN POS DESKTOP
Cap nhat gan nhat: 2026-05-07

1. Trang thai hien tai
- Du an la ung dung POS desktop viet bang Python + PyQt6.
- App dang chay theo mo hinh 1 cua so duy nhat, dung QStackedWidget de doi noi dung giua POS Terminal va Product Management.
- Database dung SQLite built-in cua Python thong qua sqlite3.
- File database chinh la pos.db nam o thu muc goc project.
- POS Terminal va Product Management dung chung database pos.db.
- Product Management quan ly bang products.
- POS Terminal doc products de ban hang, luu giao dich vao sales va sale_items.
- Backend thanh toan Cash, Split Payment, Void/Cancel da co logic co ban.
- Sau khi thanh toan thanh cong, app tao popup Receipt Preview mo phong in bill.

4. Database hien tai
- database/db.py tao cac bang neu chua ton tai bang init_db().

Bang products:
CREATE TABLE IF NOT EXISTS products (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    barcode TEXT UNIQUE,
    name TEXT NOT NULL,
    price REAL NOT NULL,
    category TEXT,
    requires_weight BOOLEAN DEFAULT 0
)

Bang sales:
CREATE TABLE IF NOT EXISTS sales (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    total_amount REAL NOT NULL,
    payment_method TEXT NOT NULL,
    created_at TEXT DEFAULT CURRENT_TIMESTAMP
)

Bang sale_items:
CREATE TABLE IF NOT EXISTS sale_items (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    sale_id INTEGER NOT NULL,
    barcode TEXT,
    qty INTEGER NOT NULL,
    price REAL NOT NULL,
    subtotal REAL NOT NULL,
    FOREIGN KEY (sale_id) REFERENCES sales (id)
)

5. Ham database dang co trong database/db.py
- get_connection()
  Mo ket noi den pos.db va tra ve sqlite3.Row.

- init_db()
  Tao products, sales, sale_items neu chua ton tai.

- get_all_products()
  Lay tat ca products.

- search_products(keyword)
  Tim products theo name hoac barcode.

- get_product_by_barcode(barcode)
  Tim dung 1 product theo barcode.

- add_product(), update_product(), delete_product()
  CRUD san pham.

- find_product_for_sale(keyword)
  Ho tro POS Terminal tim san pham khi scan/search.

- create_sale(total_amount, payment_method, sale_items)
  Luu hoa don vao sales va cac dong hang vao sale_items.

6. Product Management hien tai
- File chinh: product_management/product_management_window.py.
- La QWidget page nam trong QStackedWidget cua PosMainWindow.
- UI dung QFormLayout cho form nhap lieu nen cac field thang hang hon.
- Search realtime bang textChanged.
- Input fields:
  + Barcode
  + Product Name
  + Price
  + Category
- Checkbox:
  + Requires Weight
- Buttons:
  + Add Product
  + Update Product
  + Delete Product
- Table columns:
  + No.
  + Barcode
  + Product Name
  + Price
  + Category
  + Requires Weight
- Cot No. la so thu tu hien thi 1, 2, 3... khong phai id database.
- ID database that duoc luu an trong UserRole cua cell No. de update/delete dung record.
- Khi xoa san pham, No. tu dong danh lai theo danh sach hien tai.
- Validate dang co:
  + Product Name khong duoc rong.
  + Price phai la so hop le va khong am.
  + Barcode unique, neu trung se bao loi.
- Delete co QMessageBox xac nhan.

7. POS Terminal hien tai
- File chinh: pos_terminal/pos_window.py.
- Search/scan bar o tren cart.
- Nguoi dung nhap barcode hoac product name roi nhan Enter.
- POS goi db.find_product_for_sale(keyword).
- Neu tim thay 1 san pham:
  + Them vao cart.
  + Neu da co trong cart thi tang Qty.
  + Cap nhat subtotal va Total Amount.
- Neu khong tim thay:
  + Hien QMessageBox warning "Product Not Found".
- Neu co nhieu ket qua:
  + Hien QMessageBox warning yeu cau nhap cu the hon.
- Cart columns:
  + Barcode
  + Product Name
  + Qty
  + Unit Price
  + Subtotal
  + Action
- Cot Qty cho double-click de sua so luong.
- Neu sua Qty ve 0 hoac so am, item bi xoa khoi cart.
- Cot Action co nut Delete de xoa item thu cong.

8. Logic thanh toan hien tai
- Pay Cash:
  + Doc Total Amount tu cart.
  + Doc Tendered tu QLineEdit.
  + Neu Tendered < Total thi QMessageBox.warning.
  + Neu du tien thi tinh Change.
  + Luu vao sales voi payment_method = Cash.
  + Luu tung dong cart vao sale_items.
  + Hien QMessageBox "Payment successful" kem Change.
  + Tao Receipt Preview popup.
  + Don cart de ban don moi.

- Split Payment:
  + Mo QDialog popup.
  + Co 2 field: Cash va Card/Transfer.
  + Co nut Confirm.
  + Cash + Card/Transfer phai >= Total Amount.
  + Neu du tien thi luu vao sales voi payment_method = Split.
  + Luu tung dong cart vao sale_items.
  + Hien QMessageBox "Payment successful" kem Change.
  + Tao Receipt Preview popup.
  + Dong dialog va don cart.

- Void/Cancel:
  + Hien QMessageBox.question voi noi dung:
    "Are you sure you want to void this transaction?"
  + Neu Yes thi xoa cart, reset Total Amount ve $0.00, xoa Tendered.
  + Neu No thi khong lam gi.

9. Receipt Preview hien tai
- Sau Pay Cash hoac Split Payment thanh cong, app tao text bill va hien trong QDialog.
- Receipt co:
  + Ten cua hang: MY POS SHOP
  + Ngay gio thanh toan
  + Payment method
  + Danh sach item: ten mon, Qty, Price, Amount
  + Total
  + Tendered
  + Change
  + Loi cam on
- Receipt hien trong QTextEdit read-only voi font Consolas de can le giong bill sieu thi.
- Hien tai chua luu receipt.txt ra file; moi chi preview bang popup.
